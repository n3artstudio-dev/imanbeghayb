# مشکات غیب | پلتفرم سینمایی ایمان به غیب و کلام قرآن
> **الهام‌گرفته از دیدگاه هنری و سینمایی قرآن کریم: [@qurancinematic](https://www.instagram.com/qurancinematic/)**

یک پلتفرم تعاملی، هنری و معرفتی بر پایه Next.js (App Router)، Tailwind CSS و PostgreSQL (Drizzle ORM) که به تجسم عوالم غیب، خلقت انسان، پیام‌رسانی با نظارت وجدان و مسابقات تدبر قرآنی می‌پردازد.

---

## قابلیت‌های نسخه اولیه (V1.0)

1. **استودیوی سینمایی غیب (Cinematic Studio & VOD):**
   - سناریوهای دکوپاژ شده از خلقت انسان (نفخه روح در کالبد خاک)، عالم ذر، فرشتگان رقیب و عتید، و گذرگاه برزخ.
   - زاویه دوربین، تفکیک پلان‌ها، دیدگاه فلسفی کارگردان و پیشنهاد اتمسفر صوتی.
   - حالت تمام سینمایی (Cinematic Mode) و ابراز تأثر قلبی.

2. **آینه ضمیر و چت با «بوی خدا» (Conscience Messenger):**
   - تحلیل در لحظه کلام قبل از ارسال بر مبنای آیات نظارت حق (*أَلَمْ يَعْلَم بِأَنَّ اللَّهَ يَرَى*).
   - هشدار مهربانانه وجدان در برابر کلمات تند و خشمگین با دکمه پیشنهاد اصلاح کلام.
   - ثبت پیام‌ها در جریان نورانی عمومی.

3. **کوییز معرفتی ایمان به غیب (QuizUp Style):**
   - پرسش‌های ژرف چهارگزینه‌ای با امتیازدهی و حکمت باطنی در پایان هر سوال.

4. **دیوار روشنایی و عهد با پروردگار (Silent Vows):**
   - ثبت نجوای پنهانی، استغفار یا عهد با خدا، دریافت پاسخ قرآنی و امکان روشن کردن شمع صلوات برای دعاها.

## راه‌اندازی محلی (Local Development)

```bash
# ۱. کلون پروژه
git clone <your-repo-url>
cd <repo-folder>

# ۲. نصب وابستگی‌ها
npm install

# ۳. تنظیم متغیرهای محیطی
cp .env.example .env
# مقدار DATABASE_URL را با پایگاه داده PostgreSQL خود تنظیم کنید

# ۴. اعمال ساختار جداول پایگاه داده
npx drizzle-kit push

# ۵. اجرای پروژه
npm run dev
```
سپس به نشانی `http://localhost:3000` بروید.

## انتشار روی ورسل (Deploy to Vercel)

1. مخزن کد را به حساب **GitHub** خود پوش (Push) کنید.
2. وارد پنل **[Vercel](https://vercel.com)** شوید و گزینه **Add New Project** را بزنید.
3. مخزن گیت‌هاب را انتخاب کنید.
4. یک دیتابیس رایگان PostgreSQL مانند **Neon.tech**، **Supabase** یا **Vercel Postgres** بسازید و آدرس اتصال آن را در بخش **Environment Variables** در ورسل با کلید `DATABASE_URL` اضافه کنید.
5. پس از اولین استقرار، جداول و داده‌های اولیه به طور خودکار آماده به کار می‌شوند (یا می‌توانید با اجرای دستور `npx drizzle-kit push` از ترمینال لوکال جداول را بسازید).
